# BRAVEX Next.js

Component-based migration from static HTML to Next.js App Router.

## Start

```bash
cd bravexnext
npm install
npm run dev
```

## Routes

- `/` - Home
- `/cart` - Cart
- `/checkout` - Checkout

## Structure

- `app/components/home/*` - homepage blocks
- `app/components/cart/*` - cart page blocks
- `app/components/checkout/*` - checkout page blocks
- `app/components/Header.jsx` - shared header
- `app/components/Footer.jsx` - shared footer
- `app/components/OrderSummary.jsx` - shared summary card
